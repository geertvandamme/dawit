# What the tests check

`DawItTests` (`tests/EngineTests.cpp`) is a headless test of the engine, generate and analysis code. How to run it, and its optional real-plugin and model checks, are in the README's *Tests* section. It drives the audio callback through a fake device and checks:

- ONNX: the shared environment is reused and its platform's telemetry suppression signal is set. This does not observe network traffic or Windows ETW events.
- stem separation: splitting, cross-fading, cancellation, failures and choosing the number of pieces for different clip lengths, CPU counts and memory limits.
- transport bar in a narrow window (real app only, `--screenshots` with `"checkTransport": true`, then `"checkTransportKeyboard": "press"` and, in a later shot, `"expect"`): at 960 x 600, 1280 x 800 and 1440 x 900 no visible control has zero size or leaves the bar; Play, Stop, Record, Add Audio/MIDI Track, Mixer, Notebook and the rest each have their own button or an item of the More... menu; the items are named, unique, and match their buttons' enabled and toggled state (Loop, Metronome, Mixer, Notebook, Computer keyboard follow the engine and panels); choosing Loop, Metronome, Add MIDI track and Undo in the menu does what the buttons do; Return on the focused More... button opens the menu. The runner fails the run (exit 1) on a problem. Not covered: arrow-key movement inside the open menu (JUCE's own), focus order, and the inspector menu, close and restart paths.
- playhead following: manual suspension, remaining paused while outside or already visible, natural re-entry, repeated resume and transport intent; the real-app screenshot runner checks scroll position, the View menu tick and shortcut, and reloading the saved preference.

- piano roll velocity mode: `setNoteVelocities` raising or lowering selected notes by the same number of steps (40, 63, 127 plus 20 gives 60, 83, 127), clamping to 1..127, leaving unselected notes alone, restoring the originals at a zero change, and sending no change when nothing changes
- piano roll toolbar (`PianoRollToolbar.h`): every tool stays at a wide header, only lower-priority tools overflow at a middle width, everything is in the More menu at a tiny one, overflow never reverses as the space shrinks, the kept tools never exceed the space, the target label keeps 170 px (or what is left, at least 80)
- piano roll note menu (`notemenu::getText`): Delete is enabled only with a selection and says "Delete note" or "Delete 3 notes"; Quantise says "Clip" with no selection and "Selected Notes" with one
- the built-in synth (every sound plays, stays below full scale and ends), panning, volume, mute, note release and loop wrap-around
- note previews (in the guides' own-sound block): a *track* preview plays on a Drums, Percussion or piano track and not on DawIt's own synth, a *pitched* one on a drum track still plays on DawIt's own sound, a *drums* one plays on DawIt's own drums unless the selected track plays drums, with no track selected each kind plays on the matching own synth, a note-off follows its note-on when the selection changes, and a bounce rendered while previews are queued contains none of them
