# Third-party compiler warning review

Reviewed on 9 November 2026 against [validation run 42626719335](https://github.com/geertvandamme/dawit/actions/runs/42626719335). It checked out DawIt commit `1ad907b872ddb3ebe907ee6dda34c60269523aa4` and moved the `TestMidiPlugin::processBlock` using-declaration before its function declaration for the run. That correction is in `d82679b`; the run is not a build of the later instruments-guide commit or of a tagged release. The macOS Apple Silicon, Linux x64 and Windows x64 jobs passed their tests and packaging checks. The evidence artifacts record the ONNX Runtime inputs and CMake settings. These are compiler-warning occurrences in the logs, not counts of distinct defects; compiler, linker, CMake and Actions notices are different kinds of message.

This review applies only to the versions, locations, platforms and build settings identified below. It does not accept a warning merely because it comes from a dependency or matches a warning code. Recheck an entry if its source, configuration, compiler or warning changes. Keep warnings visible.

The accepted entries account for 63 of 1,623 macOS messages, all 57 Linux messages, and 28 of 480 Windows messages. The Windows count excludes 32 MSVC continuation lines that repeat the diagnostic code but only describe a template type. Counts do not by themselves prove safety.

## Still open

- **macOS: 1,560 warnings** in whisper.cpp 1.9.5 / ggml, all `-Wshorten-64-to-32`, at hundreds of sites. Examples include tensor dimensions, row counts and sizes converted to narrower integers. Bounds and reachability for DawIt's models and configurations have not been established. Do not accept them as a group.
- **Windows: 452 warnings:** C4267 (381), C4244 (36), C4200 (18), C4047 (16), C4018 (1). They include narrowing conversions, zero-sized-array extensions, integer/pointer conversions in Protobuf atomics and a signed comparison. Some may be intentional or build-tool-only; each still needs a source-level assessment and, where necessary, bounds or behaviour tests. For example, Protobuf `MicroString::LargeRep` stores a `size_t`-derived length in `uint32_t`; a cast alone would not establish safe bounds.
- The Linux Protobuf bounds patch eliminated the previously observed GCC overread/overflow messages, and the focused bounds checks and DawIt tests passed. The upstream Protobuf test suite has not been run; the absence of those diagnostics is not a complete security or source audit.

The newer main branch includes later application and website commits. Confirm the dependency versions, configurations and compiler diagnostics again for the exact tagged candidate. This warning review does not establish licence notices, corresponding-source completeness, telemetry suppression or clean-machine installation.
